# Super Check Partial contest calls

`morserunner.qcb` is a content-preserving copy of the Super Check Partial
`MASTER.SCP` contest callsign list. Its original header remains in the data
file; QRQ ignores the non-callsign header records and loads its 50,029 calls.

Source: <https://supercheckpartial.com/MASTER.SCP>

- Super Check Partial release: 2026.08.07
- Snapshot retrieval: 2026-08-10
- Source snapshot SHA-256:
  `d0d4322ee4dcae3beca98febdf58273f0f19907ea198c16d1e46176447bbc7d4`

The call list remains attributable to Super Check Partial. W4GNS integrated
the snapshot into this QRQ fork as a separately selectable practice database;
the source data itself is not represented as W4GNS-authored.
